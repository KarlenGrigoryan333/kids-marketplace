# Նախագիծ

Հայաստանի մանկական ապրանքների հարթակ։

## Բիզնես մոդել

- Սեփական ապրանքների վաճառք։
- Dropshipping։
- Այլ վաճառողների marketplace։

Առաջնային լեզուն հայերենն է, արժույթը՝ AMD (ՀՀ դրամ)։

## Նախատեսվող տեխնոլոգիաներ

- React/Next.js՝ օգտատիրոջ միջերեսի համար։
- C#/.NET API՝ սերվերային մասի համար։
- PostgreSQL՝ տվյալների բազայի համար։

Տարբերակները դեռ վերջնական ընտրված չեն։ Տեղադրված գործիքների տարբերակները նախագծային որոշում չեն։

## Առկա տեղեկության սահմանները

Նախկին նախատիպն ու պահանջների փաստաթղթերը դեռ այս repository չեն ներմուծվել։
Դրանց բովանդակությունը, գործառույթները և մանրամասն պահանջները դեռ չեն ստուգվել։
Հավելվածի կառուցվածքն ու իրականացման մանրամասները կորոշվեն պահանջների ուսումնասիրությունից հետո։
